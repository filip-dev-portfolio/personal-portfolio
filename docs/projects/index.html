CV / Job Description Analysis LLM

A document-focused AI application concept combining retrieval, contextual search and language models.

EXPAND DETAILS +

A Python-based application that uses Ollama and the Qwen3 8B language model to compare CVs against job descriptions and generate AI-powered matching results. The application runs locally through Docker, eliminating the need for a hosted AI API and keeping document processing on the user's machine. It supports PDF, DOCX, TXT, and Markdown files, with dedicated modules for document parsing, prompt engineering, model integration, and matching logic. A modular architecture separates configuration, inference, and processing, while storing CVs, job descriptions, and results in local directories. The project focuses on local LLM integration, containerization, document processing pipelines, and privacy-conscious AI application design.

ENGINEERING FOCUS

Retrieval quality, grounded responses and LLM integration.

PDF Tutor

A document-based learning assistant designed around asking questions about PDF content.

EXPAND DETAILS +

A Python-based application that implements a Retrieval-Augmented Generation (RAG) pipeline to answer questions about PDF textbooks using locally running language models. It extracts and cleans textbook content with PyMuPDF, generates semantic embeddings using Sentence Transformers, and retrieves relevant passages through FAISS vector search. Retrieved context is passed to Qwen3 8B via Ollama to generate grounded answers with source-page references, helping users verify responses against the original material. Built with Streamlit and persistent local storage, the application combines document ingestion, semantic search, and LLM inference into a modular, interactive learning tool. The engineering focus is on RAG pipeline design, embedding-based retrieval, context construction, local inference, and systematic evaluation of retrieval quality and answer accuracy.

ENGINEERING FOCUS

Document processing, contextual question answering and usability.
